ADIVINA LA OPERACIÓN - APP PARA CELULAR

Esta es una PWA instalable.

Android: abre el sitio publicado con HTTPS en Chrome y elige "Instalar aplicación" o "Agregar a pantalla principal".
iPhone/iPad: abre el sitio en Safari > Compartir > "Agregar a pantalla de inicio".

Para instalarla directamente como APK necesitarías convertir este proyecto a Android (por ejemplo con Capacitor/Android Studio). Esta versión permite instalarla como aplicación web sin tienda.
